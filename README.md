# Учебная 3D-вселенная для Streamlit

Этот пакет содержит публичную версию вселенной ICB 4.0 и Python-обёртку с входом по логину и паролю.

Все пять проектов созданы как самостоятельные учебные кейсы: оранжерея, выставка, велопрокат, планетарий и читательская мастерская. Организации, роли, даты, суммы, показатели и события вымышлены. Бейджи подтверждения показывают, что указано в условиях учебного кейса; они не подтверждают реальный опыт.

## Публикация на streamlit.app

Streamlit Community Cloud разворачивает приложения из GitHub. [Инструкция Streamlit](https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app/deploy).

1. Создай отдельный репозиторий GitHub.
2. Загрузи содержимое папки `ICB_Public` в корень нового репозитория.
3. Проверь, что `streamlit_app.py`, `requirements.txt`, `assets` и `.streamlit/config.toml` находятся в корне репозитория.
4. Открой `share.streamlit.io`. Нажми `Create app`.
5. Выбери репозиторий и ветку. Укажи файл `streamlit_app.py`.
6. В `Advanced settings` выбери Python 3.12.
7. В поле `Secrets` вставь настройки доступа из локального файла `.streamlit/secrets.toml`.
8. Нажми `Deploy`.

Локальный файл секретов не входит в ZIP и Git. Если локального файла нет, создай настройки командой ниже. [Секреты Community Cloud](https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app/secrets-management).

```sh
python tools/create_access.py --username demo-user
```

Команда запросит пароль два раза. Скопируй полученный блок `[access]` в поле `Secrets`. Пароль хранится как хеш с индивидуальной случайной солью.

Без корректных секретов приложение не открывает 3D-сцену. В приложении нет встроенного запасного пароля.

## Локальный запуск

Открой терминал в папке `ICB_Public`.

```sh
python -m venv .venv
```

В Windows:

```powershell
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m streamlit run streamlit_app.py --server.address 127.0.0.1
```

В Linux или macOS:

```sh
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m streamlit run streamlit_app.py --server.address 127.0.0.1
```

Открой `http://127.0.0.1:8501`. Для локального запуска сначала создай `.streamlit/secrets.toml` с блоком `[access]`.

## Как работает обёртка

Python проверяет логин и пароль на сервере. После успешного входа сервер отправляет браузеру один HTML-документ. Документ содержит только шесть файлов из `assets`. Все библиотеки 3D-сцены включены в документ. Загрузки библиотек с внешних сайтов нет.

Сцена открывается в iframe с отдельным непрозрачным источником. JavaScript сцены не может читать страницу входа. Политика CSP запрещает сетевые запросы из сцены. Поиск, масштабирование, поворот и разбор проектов работают внутри браузера.

В обёртке нет загрузки файлов, выполнения команд, подключения к базе данных и чтения пути из пользовательского ввода. Статическая раздача файлов Streamlit отключена. Защиты CORS и XSRF включены. Подробные ошибки остаются в журнале сервера. [Настройки Streamlit](https://docs.streamlit.io/develop/api-reference/configuration/config.toml).

После пяти неверных попыток за пять минут вход временно ограничивается до истечения этого окна. Ограничение группирует попытки по IP, если адрес доступен, иначе по сессии. IP можно подменить, поэтому отдельно действует общий предел: 60 проверок пароля в минуту на процесс. Ограничения сбрасываются при перезапуске приложения. Они не заменяют защиту облачной платформы от массовых запросов.

Вход действует в текущей сессии. Кнопка `Выйти` закрывает сцену. Перезагрузка страницы требует нового входа. Прогресс внутри 3D-сцены может сброситься после перезагрузки из-за изоляции iframe.

Посетитель после входа может сохранить отправленные ему HTML и данные. Вход не скрывает уже загруженный материал и не защищает авторские права. Общая демонстрационная пара доступа подходит для демонстрации. Для закрытого доступа установи другой пароль через `Secrets`.

Абсолютную защиту от взлома гарантировать нельзя. Устанавливай обновления Streamlit после проверки приложения. Не добавляй в этот пакет личные документы, исходные PDF и приватные версии вселенной. Не сохраняй токены GitHub, GitLab или другие ключи в файлах приложения.
